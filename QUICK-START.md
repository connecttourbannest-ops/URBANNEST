# ⚡ 5-Minute GitHub Upload (Super Simple)

## 🎯 Goal
Upload files to GitHub → Website goes live automatically → Share link → Done!

---

## 🚀 STEP 1: Create GitHub Account

1. Go to **github.com**
2. Click **Sign up**
3. Enter email: `connect.tourbannest@gmail.com`
4. Create password
5. Verify email
6. **You now have a GitHub account!** ✅

---

## 📁 STEP 2: Create Repository

1. On GitHub, click **+** icon (top right)
2. Click **New repository**
3. **Name:** `urbannest` (lowercase)
4. **Public** (required)
5. Click **Create repository** ✅

---

## 📤 STEP 3: Upload Files (2 minutes)

1. You'll see a page that says "Quick setup"
2. Click: **"uploading an existing file"**
3. **Drag & drop these 11 files:**

```
✓ index.html
✓ Code.gs
✓ logo.png
✓ kitchen.png
✓ bedroom.png
✓ dining.png
✓ living-room.png
✓ moodboard.png
✓ README.md
✓ GITHUB-DEPLOY.md
✓ .gitignore
```

4. Scroll to bottom
5. **Commit message:** `Initial commit`
6. Click **Commit changes** ✅

---

## ⚙️ STEP 4: Enable GitHub Pages (30 seconds)

1. Go to **Settings** (top of page)
2. Click **Pages** (left sidebar)
3. **Source:** Change to `main`
4. Click **Save** ✅

---

## ⏳ STEP 5: Wait (2 minutes)

GitHub builds your website. You'll see a green checkmark.

---

## 🎉 STEP 6: Share Your Link

Your website is now live at:

```
https://YOUR-USERNAME.github.io/urbannest/
```

Replace `YOUR-USERNAME` with your actual GitHub username.

**Example:**
```
https://john-smith.github.io/urbannest/
```
