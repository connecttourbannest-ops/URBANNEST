## ❓ FAQ

**Q: Is it free?**
A: Yes! GitHub Pages is 100% free forever.

**Q: Can anyone see my code?**
A: Yes, repository is public. That's fine - it's just HTML/images.

**Q: How long until it's live?**
A: 1-2 minutes after enabling Pages.

**Q: Can I use a custom domain?**
A: Yes! Buy domain (~$10/year) and add to Settings → Pages.

**Q: What if I make a mistake?**
A: Edit the file again, commit, and it updates automatically.

**Q: Where's my Google Sheet data?**
A: Check your Google Sheet "Responses" tab - form submissions appear there.

## 🆘 If Something Goes Wrong

**Images not showing?**
- Check file names are **exactly lowercase**: `logo.png` not `Logo.PNG`
- Hard refresh: Ctrl+Shift+R
- Wait 2-3 minutes for GitHub to rebuild

**Form not submitting?**
- Open browser console (F12) to see errors
- Verify AppScript URL is correct in index.html

**Pages not enabled?**
- Check Settings → Pages → Source is set to `main` branch
- Wait 2 minutes and refresh

**Still stuck?**
- Try uploading files again
- Make sure you're in Settings → Pages, not repo Settings
