# Urban Nest - Website Setup Guide

## 📁 Folder Structure

Keep all files in the **same folder**:

```
/your-folder/
├── index.html          (main website)
├── Code.gs             (Google Apps Script backend)
├── logo.png
├── kitchen.png
├── bedroom.png
├── dining.png
├── living-room.png
└── moodboard.png
```

## 🚀 How to Use

### Option 1: Open Locally (Instant - No Server Needed)
1. **Download all files** from outputs folder
2. **Place them in the same folder** on your computer
3. **Double-click index.html** to open in browser
4. ✅ Website works offline!

### Option 2: Host Online (Permanent)
1. Upload all files to:
   - Netlify (free)
   - Vercel (free)
   - GitHub Pages (free)
   - Any web host
2. ✅ Images load perfectly from any device

## 📝 Form Submissions

The form automatically sends data to Google Sheets:
- **Connected to**: Your AppScript URL
- **Saves**: Name, Email, Phone, Timestamp
- **Sheet tab**: "Responses" (auto-created if missing)

## ⚠️ Important Notes

- **Keep all files together** in the same folder
- **Image names are case-sensitive** on some servers
- **For offline use**: Just open index.html, no server needed
- **For online use**: Upload all files to your host

## 📞 Support

If images don't show:
1. Check all files are in **same folder**
2. Try opening in a different browser
3. Upload to a web host (free options: Netlify, Vercel)
